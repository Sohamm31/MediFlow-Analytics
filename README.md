# MediFlow Analytics

An end-to-end data analytics and simulation project exploring emergency department patient flow, forecasting patient demand, and evaluating hospital resource allocation strategies.

**Technologies:** Python, Pandas, PostgreSQL, SQL, scikit-learn, SimPy, Monte Carlo simulation, optimisation, Streamlit and Plotly.

**Objective:** Investigate how data-driven forecasting and simulation can help evaluate strategies for reducing patient waiting times and managing emergency department capacity.

**Data note:** Results based on synthetic data will be clearly labelled and will not be presented as evidence of real-world hospital improvements.
